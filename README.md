## 🚀 How to Run Any App

```bash
# Navigate to the specific day's folder
cd ComponentShowcaseApp

# Install dependencies (first time only)
npm install

# Start the Expo development server
npx expo start

# Then scan the QR code with Expo Go on your mobile device
```
